Coin Faucet
Get test tokens for sandbox development using the MNEE CLI

Note: The faucet only works in the sandbox environment.

Quick Start Guide
1
$ npm i -g @mnee/cli
Install the CLI globally

2
$ mnee
Verify installation

3
$ mnee create
Create key (select sandbox)

4
$ mnee login
Authenticate the developer portal

5
$ mnee faucet
Request tokens

Limits: 10 MNEE tokens per request, once per 24 hours.
