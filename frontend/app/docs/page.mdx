
# Introduction

Welcome to the Coal API documentation. Coal is the comprehensive payment rail for **MNEE**, ensuring you can build stablecoin flows for any application.

## What is MNEE?

MNEE (pronounced “money”) is a fast, USD-backed stablecoin designed for digital payments, gaming, and remittances.

*   **⚡ Instant Transactions**: Send and receive in under a second.
*   **💸 Low Fees**: Microtransactions are finally viable.
*   **🌍 Multi-Chain**: Works across Ordinals and Ethereum ecosystems.

Coal abstracts the complexity of MNEE ledgers, providing a clean REST API for merchants and developers.
